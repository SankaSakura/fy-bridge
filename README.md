# FY 本地反代 1.0

说明：本项目通过 AI 辅助编程（vibe coding）完成。

通过浏览器里已登录的 FY 账号，把文本聊天客户端的请求转发到 FY，再将回复返回客户端。适用于文本聊天和角色扮演客户端，提供 Chat Completions 兼容接口。

只需首次安装时运行安装程序，之后在浏览器扩展中启动或停止反代。密钥自动生成并填入扩展，不需要打开 TXT 文件复制。

## 安装前准备

- Windows 10 或 Windows 11。
- 安装 [Node.js 22 或更高版本](https://nodejs.org/)。安装时保留添加到 PATH 的默认选项。
- Chrome 120 或更新版本，或新版 Microsoft Edge。
- 能正常登录并使用 [FY（AI 风月）](https://aifun.wiki/zh) 的账号。

在 [GitHub Releases](https://github.com/SankaSakura/fy-bridge/releases/latest) 下载 `fy-bridge-1.0.0-windows.zip`，将整个文件夹解压到固定目录，例如 `D:\Tools\fy-bridge`。也可以下载仓库源码使用。**不要只保留 `extension` 文件夹，也不要直接在压缩包中运行安装程序。** 安装后本地启动器会使用这个目录中的文件。

发行包不包含预设卡片、账号或密钥。每位用户首次连接时选择自己的专用卡，本地服务会生成独立密钥。

## 第一次安装

### 1. 运行安装程序

双击根目录的 **`安装FY反代.cmd`**。安装程序会登记浏览器启动器，并用 Chrome 打开安装引导页。一般不需要管理员权限。

如果使用 Edge，在项目目录打开终端，执行：

```powershell
.\安装FY反代.cmd -Browser Edge
```

安装程序需要 Windows 的 .NET Framework 编译器；若提示缺少编译器，请安装或修复 .NET Framework 4.8 后重新运行。

### 2. 在浏览器加载扩展

按安装引导页完成以下操作：

1. 复制管理页地址，在浏览器地址栏粘贴并按回车。Chrome 使用 `chrome://extensions/`，Edge 使用 `edge://extensions/`。
2. 开启右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”（部分浏览器显示“加载解压缩的扩展”）。
4. 复制引导页给出的扩展目录，在文件夹选择窗口粘贴并选择。
5. 在浏览器扩展菜单找到 **FY 本地反代**，点击打开设置页；可以将它固定到工具栏，方便以后使用。

浏览器的首次加载确认需要手动完成。无需填写或复制扩展 ID。若安装程序没有自动打开引导页，可以用浏览器打开项目中的 `.local\native-messaging\install-guide.html`。

### 3. 准备 FY 专用卡

在安装扩展的同一个浏览器中登录 FY，新建一张只用于反代的空白卡：

- 主提示词只填 **一个空格**。
- 其他提示词、世界书、Mod 等内容全部留空。
- 记忆设为 **0**。
- 不开启摘要、记忆宫殿、自动生图等额外功能。
- 在 FY 中选择要使用的模型。客户端指定的生成参数会临时应用到该模型；任务结束后恢复原值，模型本身不会被替换。

打开这张卡的**对话页面**。扩展需要的地址类似 `https://aifun.wiki/zh/explore/installed/…?preview=1`，不是作品介绍页或卡片编辑页。FY 的网站域名仍是 `aifun.wiki`。

### 4. 连接专用卡

1. 打开 FY 本地反代的扩展设置页，展开“连接配置”。
2. 从“浏览器中已打开的卡片”选择专用卡，或在上方直接粘贴它的对话页面链接。看不到刚打开的卡片时，点击“刷新卡片列表”。
3. 本地服务地址通常保留默认值。
4. 点击 **“启动反代”**。这一步会自动保存配置、启动本地服务并取得密钥；也可以先点“保存配置”，稍后再启动。

出现“反代已启动，等待客户端请求”即表示可以接入。首次安装不需要再运行手动启动脚本。每张专用卡只保留一个对话标签，避免连接到重复页面。

### 5. 在聊天客户端填写连接参数

选择客户端中的 **OpenAI 兼容 / Chat Completions** 接口，然后展开扩展设置页的“API 地址、模型与密钥”，分别复制三个参数。

| 客户端中的设置 | 应填写的内容 |
| --- | --- |
| API 地址 / Base URL | 默认 `http://127.0.0.1:43119/v1`；改过端口时，以扩展显示为准 |
| 模型名 | `fy-current`，请完整填写；实际使用的模型在 FY 专用卡中选择 |
| API 密钥 | 点击扩展中的“复制 API 密钥”，粘贴到客户端 |
| 请求超时 | 建议至少 210 秒 |

完成后即可从客户端发送消息。完整历史上下文由客户端提供；FY 记忆为 0，网站里的历史记录不会作为额外上下文重复发送。

## 平时怎么用

- **继续使用：**保持浏览器运行。未手动停止反代时，下次启动浏览器会沿用已保存的配置，自动打开专用卡并连接。
- **关闭设置页：**连接成功后，看到“此页可以关闭”即可关闭设置页；浏览器和 FY 卡片标签仍需保留。
- **停止反代：**点击“停止反代”。若有请求正在处理，会先取消请求并恢复原配置，再关闭由扩展启动的本地服务。手动停止后不会自行续接，需要再次点击“启动反代”。
- **更换专用卡或端口：**先停止反代，再展开连接配置修改并保存。端口改变后，客户端 API 地址也要更新。

处理请求时不要刷新专用卡、切换会话或手动修改卡片配置。已打开对话会继续复用；处于“新对话”时，第一个请求创建对话，后续请求继续使用它。

## 更新与卸载

**更新：**先停止反代，确认没有恢复提示，再退出浏览器。保留 `.local` 文件夹，将项目文件更新到原目录，重新运行 `安装FY反代.cmd`，最后在扩展管理页点击“重新加载”。固定扩展身份不会因版本更新而改变；已保存的卡片和密钥可继续使用。

如果移动了整个项目目录，也需要重新运行安装程序，并在扩展管理页重新指定新的 `extension` 目录。

**卸载：**先停止反代，再在浏览器扩展管理页移除 FY 扩展。需要同时移除本地启动器登记时，在项目目录执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\native\uninstall.ps1
```

Edge 用户在命令末尾加 `-Browser Edge`。卸载脚本不会删除密钥；确认不再需要后，可以自行删除整个项目目录。

## 常见问题

**提示本地启动器不可用**

确认 Node.js 已安装，然后重新运行 `安装FY反代.cmd`。Chrome 和 Edge 的登记分别安装；在 Chrome 安装过，不代表 Edge 也已安装。更新时提示文件被占用，请停止反代并退出浏览器后重试。

**提示专用卡重复、未登录或无法读取**

在同一个浏览器中登录 FY，打开所选专用卡的对话页面，关闭同一卡片的重复标签，再重新启动反代。

**提示需要恢复原配置**

正常生成过程会自动备份和恢复配置，不需要手动操作。只有中断或恢复失败后才会出现恢复入口。保留专用卡标签，确认没有其他生成，再点击“恢复保存的原配置”；没有备份时，按界面提示先在 FY 手动恢复，再解除阻塞。恢复操作不会重新生成回复。

**客户端返回 400**

先查看错误详情。模型名必须是 `fy-current`。当前只接受文本消息，不支持工具调用、多模态。支持 `max_tokens`、`temperature`、`top_p`，会按 FY 当前模型声明的能力和范围检查；不支持的参数或超出范围会明确失败，不会悄悄忽略。具体支持范围见 [API 与技术说明](docs/fy-bridge.md)。

**客户端返回 502、超时或取消**

打开扩展设置页查看错误提示，先确认 FY 中是否已经有回复，再决定是否重试。工具不会自动重发失败请求；本地取消不能保证 FY 已开始的生成立即停止，也不能撤销已发生的用量。

**想在终端手动运行服务**

`手动启动服务.cmd` 是供排错或自定义参数使用的备用入口，日常使用无需打开。手动启动后仍需在浏览器扩展中点击“启动反代”；服务需要在原终端按 Ctrl+C 关闭。

## 能力与限制

支持 `system`、`user`、`assistant` 文本消息。系统指令与用户输入分别注入；历史消息按顺序作为文本上下文传入，不导入 FY 的原生历史角色。暂不支持工具调用、图片、音频或视频。流式接口会在整段回复生成并恢复配置后返回，不能实时逐字显示。

服务只监听本机 `127.0.0.1`。密钥和本地运行文件位于 `.local/`，请勿把这个文件夹上传或打包分享给其他人。

后台会将完整 FY 请求和原始响应写入 `.local/fy-bridge/logs/fy-traffic-YYYY-MM-DD.log`，解析失败时也保留已收到的数据。日志包含完整提示词、历史对话、回复及卡片配置，不包含 Cookie 或 API 密钥，不会自动上传或清理。查看格式和接收中断的处理方式见 [请求与响应日志说明](docs/fy-bridge.md#fy-请求与响应日志)。

首次使用建议先发送一条短消息，确认客户端与 FY 均能正常接收回复。FY 网站接口发生变化时，可能需要更新本工具。

## 技术栈与目录

使用 Node.js 原生 HTTP 服务、Chrome/Edge Manifest V3 扩展，以及 Windows Native Messaging 启动器；运行服务不需要安装 npm 依赖。扩展通过已登录的 FY 页面发送请求，不导出网站 Cookie。

| 位置 | 用途 |
| --- | --- |
| `安装FY反代.cmd` | 首次安装和更新入口 |
| `手动启动服务.cmd` | 手动运行服务的备用入口 |
| `extension/` | 浏览器扩展、设置页和 FY 页面适配 |
| `native/` | 安装、卸载、本地启动器和安装引导页 |
| `server.mjs`、`protocol.mjs` | 本地 API、请求排队与消息转换 |
| `local-paths.mjs` | 本地数据目录及旧版密钥迁移 |
| `docs/fy-bridge.md` | 接口范围和技术说明 |
| `.local/` | 安装后生成的密钥、日志和启动器；不随源码分发 |
